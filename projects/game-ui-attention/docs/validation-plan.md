# 验证方案

状态：验证计划，未执行。本文件不包含通过记录。

## 1. 工程正确性

使用原创合成图片和人工构造的概率图，验证程序自身；合成图只能证明计算链正确，不能证明人会看哪里。

| 检查 | 预期 |
| --- | --- |
| 概率归一化 | 全图非负、有限，sum 在约定误差内为 1；初始单元检查容差建议 1e-6，实现在精度约束下固定 |
| 均匀图 | 任一区域 mass 等于面积占比，relative_density 为 1 |
| 已知局部质量 | 手工分配概率的区域统计与解析结果一致 |
| 坐标映射 | 横屏、竖屏、缩放和边界 AOI 正确落到原图 |
| 区域校验 | 零面积、越界、自交和重复 ID 被拒绝 |
| 重叠 | 分区独立显示，汇总使用掩码并集，无重复计数 |
| 标注变更 | 仅重算统计，保留相同底层概率图哈希 |
| A/B 自比较 | 相同结果差值为 0；缺失区域不补 0 |
| 配置不兼容 | 模型、权重、预处理、先验或尺寸变化时拒绝正式比较 |
| 色阶 | A/B 展示使用相同范围，浮点数据不受颜色和透明度影响 |
| 失败恢复 | 权重缺失、OOM、无效输出、路径冲突无假成功且不覆盖旧结果 |
| 文本呈现 | 区域标签和评审文本转义，HTML 不执行输入脚本 |

## 2. 可复现性与性能

记录代码/依赖版本、全部权重哈希、预处理、先验、输入图片哈希、设备类型、精度、运行时间与资源使用。

同设备同配置重复运行，先测数值差异再固定回归容差。跨设备单独建立容差，不能直接要求逐位一致。耗时区分下载、冷启动、模型推理、统计和报告生成。

未测之前不承诺 GPU 型号、内存预算或响应时间。初始兼容性验证只覆盖实际测过的环境。

## 3. 游戏 UI 试用

准备建议 20～30 张获准截图，按画面类型、复杂度、分辨率和目标分组。为每张记录玩家任务、区域角色与已知问题；避免只选模型表现好的样例。

评审有用性由设计人员检查：意见是否有截图/数值证据、是否符合任务、建议是否可执行、是否把立绘吸引注意误判为错误。

人工认可建议属于评审有用性证据，不能视为眼动预测准确率。

## 4. 预测有效性

（G0 接口锁定，2026-09-11：本节拆分为公开数据评估与游戏 UI 评估两部分；公开数据侧口径以 [research/benchmark-protocol.md](research/benchmark-protocol.md) 为唯一规范来源。）

### 4.1 公开数据评估（协议已锁定，评估未运行）

- **指标口径（冻结）**：IG（默认基线 CB，另报 IG_U）、NSS、CC、sAUC、AUC-Judd、KL(F‖S)（SIM 可选）；精确公式、float64/log2 约定、σ=1° 视角模糊换算、to_density 数值防护原语（λ=1e-8、常数图记 0+flag）见协议 §6，禁止 8-bit 中间存储参与计算。
- **划分（冻结规则）**：UEyes 官方 info.csv train/test 标志为默认冻结划分；备选确定性哈希分组划分见协议 §3.3。反泄漏五规则：近重复感知哈希簇不跨划分、同源分组、基线/先验/超参只准用 train 划分估计、见过 train 的权重禁止报 train 分数、每次运行过泄漏审计清单。
- **基线（冻结）**：均匀分布 U + 数据驱动中心偏置 CB（train 划分注视点 2D 直方图构造，按数据集×窗口×划分版本化）；每个报告表必须含 U 与 CB 行，基线 sanity 不过则脚本失败退出，不产出假成功。
- **窗口（冻结）**：1s/3s/7s 为同一 trial 前缀截断的嵌套真值，所有指标按窗口分别计算分别报告，禁止混合或池化。
- **统计（冻结）**：逐图计算；图像级 bootstrap（B=2000、固定种子、按类别分层）；模型比较用同图配对差值 CI + Holm 校正；禁止像素级独立样本假设；参与者级不确定性列为限制声明。
- **混表禁令**：UEyes 官方 eval 实现与本协议口径存在系统性偏差（IG 无真实基线、KL 方向相反、AUC 0.7 阈值、NSS 掩码语义，差异表见协议 §6.8），且论文 Table 2 有校准勘误——本项目复现分数与论文/官方分数一律不得混表；文献参考值只进独立小表并附口径差异声明。
- **成功判据**：S0（管线自检）/S1（基线有效性）/S2（候选须每窗口 IG_CB 与 NSS 配对差值 CI 下界>0 vs CB）/S3（跨数据集方向一致性，定性）/S4（相对 UMSI++ 阈值，暂缓定量）——**均为建议值，待一级总控确认后生效**；S2 不达标时只能表述为"在公开 UI 数据上未显著优于中心偏置基线"。
- **数据状态**：UEyes 12.9GB（CC-BY-4.0，md5 已录）下载待一级总控批准；获批前评估代码以合成数据自测（合成数据只能证明计算链正确）。FiWI 许可未核实前不下载不纳入。

### 4.2 游戏 UI 评估（数据缺失，保持未验证）

只有取得独立眼动数据后才评价游戏 UI 上预测与真实注视的一致性。记录参与者、设备、观看距离、展示时长、初始注视和任务条件；自由观看和带任务观看分开分析。截至 2026-09-11，可达渠道内未核实到公开可下载的游戏 UI 眼动数据集（协议 §2.5）；无自采数据时游戏 UI 预测有效性**只能标记未验证**，公开 UI 数据结果不得外推为游戏结论。

使用独立留出样本，按界面或游戏来源划分，避免近似截图同时进入适配和测试。报告按截图/参与者组织的不确定性，不能把相关的每个像素当独立样本。

现有 UI 显著性研究可作方法参考，但不直接证明本工具适用于游戏；参见[来源记录](sources-and-decisions.md)。

## 5. 可声明的结论

| 证据 | 可以声明 | 不能声明 |
| --- | --- | --- |
| 文档与链接检查 | 文档结构和链接检查通过 | 工具可运行 |
| 合成概率图测试 | 区域和概率计算通过 | 模型预测人类注意力准确 |
| 本机推理成功 | 在记录环境下可运行 | 所有设备兼容 |
| 人工试用反馈 | 对特定设计评审有帮助 | 真实玩家必然按该顺序观看 |
| A/B 指标差异 | 模型预测分布发生变化 | 点击率或任务效率因而提高 |
| 独立眼动评估 | 在记录样本和条件下的预测表现 | 对所有游戏和玩家普遍有效 |

## 6. 首版验收记录模板

每次验收记录版本、范围、输入和配置哈希、执行环境、实际检查及结果、失败案例、未验证项和结论。产物应明确标注 `模型预测`。
