# 内部粗标注一致性检查 — 研究协议

版本：v1（A1 子任务交付）。撰写日期：2026-09-13。
状态：研究协议草案，供二级总控评审；修订需递增版本号并保留旧版可追溯。

---

## 0. 目的与边界（必读）

本项目已交付游戏 UI 注意力评估 CLI（`foveacast-onnx-3s-v1` 主后端）。已知缺口：模型训练分布为西方桌面/移动 UI，**不含游戏 UI**，绝对数值不可信。本协议建立一条**内部粗标注一致性检查**线：

1. 同事自由观看游戏截图数秒后，凭记忆标出「第一眼落点」与「主看区域」（粗标注）；
2. 与模型预测做一致性打分（模型在我们 UI 上是否与人一致）；
3. 得到第一个「模型在游戏 UI 上是否与人一致」的内部校准数字；
4. 攒下首批自有标注数据（非眼动，是主观回忆式粗标注）。

**本协议产出的是「粗标注—模型一致性」证据，不是眼动有效性证据。** 粗标注 ≠ 眼动真值（见 §6）。任何单一数字不得被称为「预测准确率」「命中率」或「真实注视时长」。

### 0.1 可公开性

本文档可公开：不含截图本体、不含参与者数据、不含本机路径、不含凭据或个人身份信息。截图本体仅存在于 `local-data/`（Git 忽略目录）内，不得进入仓库。

### 0.2 与主项目口径关系

- 一致性打分的区域统计（`probability_mass / area_fraction / relative_density`）沿用[技术方案](../docs/technical-design.md) §7 的 AOI 统计口径；
- 中心偏置先验为**参数化 2D 高斯**（σ 按图尺寸比例，见 §5），是实验假设，**不得宣称为「游戏玩家的中心偏置」**（与[技术方案](../docs/technical-design.md) §5 一致）；
- 本线不构造数据驱动中心偏置（无眼动数据可拟合），与[基准协议](../docs/research/benchmark-protocol.md) §4.2 的数据驱动 CB 不同，两者不得混用。

## 1. 参与者

- 目标 **5–10 人**，内部同事，自愿参与。
- 匿名化：每位参与者仅在开始页自行填写一个**匿名 participant id**（如 `p01`、自拟代号），系统**不收集姓名、工号、账号**。
- 参与者身份信息不落盘、不外传；participant id 仅在本地结果 JSON 中作为分组键。

## 2. 观看条件

- 每图**自由观看 3 秒**（默认，可配置为 5 秒），观看时长写入 `config.json` 与每份结果 JSON。
- 流程（由 `tools/index.html` 强制，纯客户端）：
  1. 说明页 + 知情同意（§4）→ 填写 participant id；
  2. 每图：注视十字 500 ms → 图片展示 N 秒（进度条）→ 掩膜遮挡 → 凭记忆作答；
  3. 作答：点选 1 个「第一眼落点」+ 拖框 1–3 个「主看区域」；
  4. 全部完成后，结束页**下载结果 JSON**（不自动上传任何内容）。
- 观看时长是研究参数，不推断时间维度模型结论；本线模型推理是静态截图，与观看时长无关（时长只决定人侧真值，与[基准协议](../docs/research/benchmark-protocol.md) §5 一致）。

## 3. 图序随机化与种子记录

- 图片展示顺序由生成器以固定种子 `random.Random(seed).shuffle` 随机化；
- **种子写入 `config.json`**（`shuffle_seed`），保证图序可复现；
- 同一 `study_id` 的不同分发副本使用相同图序；图序只影响人侧观看顺序，不影响模型侧（模型对静态截图推理，与顺序无关）。
- 如需每参与者不同图序：为每个分发副本重新生成（新种子），并在回收时按 `study_id` 分组；**默认单批使用同一图序**。

## 4. 指导语与知情同意文案

### 4.1 指导语（展示于说明页，随 `index.html` 分发）

> 你将依次看到若干张游戏界面截图。每张图先出现一个十字，请把视线移到十字中心；随后图片显示 3 秒，请**自然观看**（不要刻意记忆某个细节）；图片隐藏后，请凭**记忆**完成两项标注：
>
> 1. **第一眼落点**：点击你「第一眼落在画面上的位置」；
> 2. **主看区域**：拖拽画出 1–3 个你「主要看过的区域」的方框。
>
> 没有标准答案，凭直觉即可。全部完成后点击下载结果文件并交回。

> - 本检查仅用于**内部校准**：衡量注意力预测模型与人的主观回忆是否一致，不评估你的个人表现，不做任何考核；
> - 你的标注**仅保存在本地**，只以匿名 participant id 标识，不收集姓名/账号等身份信息；
> - 数据**不上传任何服务器、不进入代码仓库**；结果由你下载后手动交回；
> - 截图素材为已获授权的内部截图，仅用于本研究；

>
> 勾选「我已阅读并同意上述说明」后进入。

## 5. 一致性打分口径

`tools/consistency.py` 读取 `config.json`（图清单+sha256+顺序种子+时长）、回收的 responses JSON、以及模型分析结果（对同批图片跑 `ui-attention analyze` 得到的 run 目录，或复用既有 run 目录，按 `analysis.json` 的 `input.image_sha256` 对齐）。逐图/逐人指标：

| 指标 | 定义 | 语义 |
| --- | --- | --- |
| 第一眼落点密度百分位 | 模型概率图上，人「第一眼落点」处密度值在全图像素密度分布中的百分位（`(count_less + 0.5·count_eq) / N`） | 0.5=中位，越接近 1 说明模型在该点给出越高的相对密度 |
| 主看框 mass | 人标注框（并集去重）内模型 `probability_mass = sum(P[R])` | 预测分布落入主看区域的质量 |
| 主看框 area_fraction | `area(R)/area(image)` | 面积占比 |
| 主看框 relative_density | `mass / area_fraction` | 相对密度（与技术方案 §7 同口径） |

对照基线（同口径打分）：

- **均匀基线 U**：`U(p)=1/N`。任意点百分位恒为 0.5；框 mass=area_fraction、relative_density=1。
- **中心偏置先验 CB**：参数化 2D 高斯 `CB(x,y) ∝ exp(−((x−cx)²/2σx² + (y−cy)²/2σy²))`，中心 `(cx,cy)=(W/2,H/2)`，**σx=σ_ratio·W、σy=σ_ratio·H**，`σ_ratio` 默认 `0.25`（可配置，**参数写入报告**）。归一化 `sum=1` 后与模型同口径打分。

**模型 vs 基线 win-rate**：逐 `(participant, image)` 配对比较（模型分 > 基线分记为 1 次胜），`win_rate = 胜次数 / 配对数`；分别对「第一眼落点百分位」「主看框 mass」「主看框 relative_density」报告模型 vs CB、模型 vs U。

**聚合**：均值/中位数，并按 `screen_type` 分组（无类型信息时归入 `unknown`）。

## 6. 局限性声明（必写，随报告输出）

1. **粗标注 ≠ 眼动真值**：本线真值是「主观回忆式标注」，存在记忆偏差（图片隐藏后才作答）、语言/理解偏差与标注噪声；不得与眼动注视点/注视时长等同，也不得外推为真实视觉行为。
2. **非眼动、非点击、非任务成功**：第一眼落点与主看区域是主观判断，不代表真实扫视路径、点击或任务完成。
3. **样本量小**：5–10 人 × 少量截图，**不做显著性检验、不宣称统计显著**；数字仅作内部方向性参考与首批数据积累。
4. **中心偏置是实验假设**：参数化 2D 高斯先验非从人数据拟合，是记录在案的显式假设；均匀基线不能消除模型全部中心偏好。
5. **观看条件简化为固定时长自由观看**：不覆盖 HUD 运动、场景切换、玩家目标与熟练度（与[技术方案](../docs/technical-design.md) §8 一致）。
6. **绝对数值不可信**：模型训练分布不含游戏 UI，本线数字只回答「与粗标注的相对一致性」，不修正绝对数值。

## 7. 排除标准

回收的 responses JSON 逐份检查，满足任一条即**整份或逐图排除**并记录：

1. **未看完**：`completed != true`，或 `images` 条目数 < `config.images` 总数，或中途异常终止；
2. **未作答**：某图 `responded != true`（无第一眼落点或 0 个主看框）；
3. **乱点自检**：存在明显乱填迹象——例如全部图片第一眼落点完全相同且主看框完全相同（脚本可判）、作答时间远短于观看时长下限（`display_ms` 显著低于 `duration_seconds×1000` 的某阈值）、或坐标恒落在同一点；
4. **错图绑定**：response 中某图 `sha256` 与 `config.images` 对应项不一致（防错图）；
5. **越界**：落点/框坐标超出图片像素范围（前端已钳制，作为损坏数据兜底）。

排除统计写入报告（`excluded_participants` / `excluded_images` + 原因），不进入指标聚合。

## 8. 数据流向与隐私

- 纯静态 HTML + 本地 CLI，**无任何服务、无上传 API、无外链**（`index.html` 零外链/零 `fetch`/零 `sendBeacon`/零 data:URI 内嵌大图，生成器与测试双重断言）。
- 截图副本仅进入 `local-data/calibration-package/`（`**/local-data/` 已被仓库忽略）；`calibration/tools/` 只放代码与模板，不入截图副本。
- 一致性报告输出到 `local-data/calibration-outputs/`（忽略目录）。
- 分发方式：**拷贝 `local-data/calibration-package/` 整个文件夹（或放入共享目录）给参与者**，对方用浏览器打开 `index.html` 即可；完成后交回下载的 `responses/*.json`。

## 9. 交付物与运行

| 文件 | 职责 |
| --- | --- |
| `calibration/tools/make_study_package.py` | 图片目录+配置 → 复制图片 + 实例化 `index.html` + `config.json` |
| `calibration/tools/index.html` | 模板（`__STUDY_CONFIG__` 占位，被生成器实例化） |
| `calibration/tools/consistency.py` | 一致性打分 + 基线 + win-rate + 报告 |
| `calibration/tests/` | 单测（合成 responses 断言 + 基线 win-rate 边界）与生成器自测 |

运行环境：项目 venv（`.venv`），`PYTHONPATH=src`。

```text
python calibration/tools/make_study_package.py --images local-data/screenshots --duration 3 --seed 20260913
python calibration/tools/consistency.py --package-config <pkg>/config.json --responses <dir> --runs <runs-dir> --sigma-ratio 0.25 --out local-data/calibration-outputs/<id>
```
