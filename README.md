# K-Agents-toolbox

面向 AI Agent 的工具与技能项目集合。每个项目独立记录用途、技术方案、实施进度和验证边界。

## 项目

| 项目 | 用途 | 当前状态 |
| --- | --- | --- |
| [Game UI Attention](projects/game-ui-attention/README.md) | 游戏 UI 视觉注意力预测、重点区域统计与视觉层级评审 | G0-G3 全部验收（CLI+Skill+UEyes 公开基准评估，535 测试通过）；游戏 UI 有效性未验证、未发布 |

## 目录约定

```text
projects/
  <project-name>/
    README.md          项目入口、状态与文档导航
    docs/              技术方案、接口、实施及验证文档
```

实际代码、模型、Skill 和示例在对应项目实施时加入。文档中的拟定接口与示例不代表工具已经可用。

## 使用与发布边界

- 当前仓库仅包含项目规划文档，没有可安装的 Skill 或可运行的分析程序。
- 每个项目分别记录第三方代码、模型权重和数据的来源与许可；公开可读不等于已取得集成或分发许可。
- 仓库当前未指定整体许可证，后续正式发布前明确原创内容和第三方资产的许可范围。
- 不提交凭据、内部项目截图、第三方模型权重或未获授权的数据。
